Signed Pacman repository for Arch Linux x86_64. Debian-signed kernel, modules,
systemd-boot and Shim are repackaged without changing their signed payloads.

Repository URL:
https://github.com/CReimer/arch-debian-kernel/releases/download/repository

See the README for the signing-key fingerprint, installation instructions and
Secure Boot limitations. These packages do not automatically enroll firmware
keys or change the selected bootloader. EAC compatibility is not established.
